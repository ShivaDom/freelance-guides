How to Write a Clear Research Abstract

Many readers only read the abstract, so it must stand alone.

Four parts

  1. Problem: what gap or question.
  2. Method: what you did, in one sentence.
  3. Result: the main finding, with a number if you have one.
  4. Meaning: why it matters.

Write it last, cut every sentence that is not one of these, and keep to the journal's word limit. Prompts for tightening abstracts are in The Researcher's AI Prompt Pack.
